# Sistema Integrado Sulnet v47

Inclui módulo de Configuração de Análise de Crédito no menu **Análise de Crédito**, disponível para admin/gerência.

## Novidades v47

- Aba **Configuração de análise** dentro de Análise Cadastral CPF/CNPJ.
- Cadastro de regras por score mínimo/máximo.
- Máximo de restrições.
- Permitir ou bloquear protesto.
- Decisão automática: Aprovado, Pré-aprovado, Análise manual ou Reprovado.
- Risco: Baixo, Médio, Alto.
- Simulador de parecer.
- Aplicação automática da regra ao salvar a análise BKO.
